# Rush Line

콘과 느린 차를 피해 결승선까지 최대한 빨리 달리는 1인칭 레이싱 게임입니다. HTML 파일 하나로 동작하며 별도 설치가 필요 없습니다.

**▶ 라이브 데모: https://donghee-ai.github.io/project_ax/**

## 조작법

| 키 | 동작 |
| --- | --- |
| ← → | 조향 |
| ↑ | 가속 |
| ↓ | 감속 |
| Space | 부스터 사용 (노란 번개 상자를 먹으면 충전) |
| Enter / Space | 시작 |
| R | 다시 시작 |

## 규칙

- 콘이나 차에 부딪히면 속도가 크게 줄고 충돌 횟수가 올라갑니다.
- 도로 밖으로 나가면 최고 속도가 절반으로 떨어집니다.
- 최고 기록은 브라우저에 저장됩니다.

## 로컬에서 실행

`index.html`을 크롬이나 엣지로 열면 됩니다. 키보드가 필요하므로 PC 브라우저에서 플레이하세요.
